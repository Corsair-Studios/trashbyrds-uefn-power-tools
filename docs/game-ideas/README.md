# Game Ideas Backlog

Early-stage UGC game concepts to consider building for **UEFN (Fortnite)** and **Roblox**.
These are ideas only — nothing here is committed or scoped yet.

| Concept | One-liner | Status |
|---|---|---|
| [One Shot Rogue](one-shot-rogue.md) | Clear a randomized chain of skill challenges with zero failures to reach the end. | Idea |
| [Pressure Kicker](pressure-kicker.md) | Physics-based field goal kicking against wind and distance. Spin-off of a One Shot Rogue event. | Idea |
| [3D Hidden Object Hunt](hidden-object-3d.md) | A classic hidden-object view, except the objects are real 3D props you run in and collect before time runs out. | Idea |

## Status key
- **Idea** — captured, not evaluated
- **Exploring** — prototyping / checking feasibility
- **Greenlit** — scoped and scheduled
- **Parked** — decided not to pursue for now
